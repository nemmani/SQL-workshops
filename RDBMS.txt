RDBMS: Relational database management System
---------------------------

- It is a type of database system used to store data, organize , manage, retrieve data 
- Purpose is data storage
- SQl queries retrieval the data
- Insert, update, delete we can data manipulation
- there is a relationships between one table to another table
- While working with tables prevent duplicates values we can apply data integrity 
- backup & recovery
- reports
